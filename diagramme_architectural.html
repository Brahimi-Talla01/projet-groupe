🎓 Architecture SaaS - Système de Gestion Scolaire

1Couche Présentation (Frontend)

🌐 Application Web

Interface responsive pour administrateurs, professeurs et élèves
Technologies:
  • React.js + TypeScript
  • Tailwind CSS
  • Redux Toolkit

📱 Application Mobile

App native pour parents et élèves avec notifications push
Technologies:
  • Dart & Flutter
  • Firebase Push
  • Offline Storage

2Passerelle API (API Gateway)

🚪 Passerelle Centrale

Point d'entrée unique pour tous les microservices
Fonctionnalités:
  • Routage intelligent
  • Authentification JWT
  • Rate Limiting
  • Load Balancing

🔐 Sécurité

Couche de sécurité centralisée avec WAF
Protection:
  • DDoS Protection
  • SQL Injection
  • XSS Prevention

3Couche Services Métier (Microservices)

🔑 Service Authentification

Gestion des connexions et autorisations
API Endpoints:
  • POST /auth/login
  • POST /auth/refresh
  • GET /auth/verify

👤 Service Utilisateur

👤 Service Utilisateur

Gestion des profils élèves, parents, professeurs et admins
API Endpoints:
  • GET /users/profile
  • PUT /users/{id}
  • POST /users/link-parent

🏫 Service Inscriptions & Classes

Gestion des inscriptions, affectations et mutations
Entités:
  • Élève ↔ Classe
  • Inscription annuelle
  • Transferts

📚 Service Matières & Programmes

Gestion des matières par filière (C, TI, F4) et système (Fr/En)
Spécificités:
  • Notes /20 ou /100
  • Coefficients paramétrables
  • Programmes officiels

🧮 Service Notes & Bulletins

Cœur de la V1 : saisie, calcul, génération PDF
Workflow:
  • Saisie → Validation → Génération
  • Moyenne, rang, appréciation
  • Blocage si impayé

⚖ Service Discipline

Suivi des absences, retards, sanctions
Acteurs:
  • Surveillant de secteur
  • Surveillant général
  • Historique par élève

💰 Service Financier

Gestion des frais et intégration Mobile Money
Paiements:
  • Orange Money, MTN MoMo
  • Factures & reçus
  • Blocage accès bulletin

🗃 Service Fichiers

Stockage et génération des bulletins PDF
Formats:
  • PDF officiel (BEPC, Bac)
  • Photos élèves
  • Pièces justificatives

🌐 Service Internationalisation

Support natif FR / EN pour les deux sous-systèmes
Fonctionnalités:
  • Interface dynamique
  • Formats de date/note adaptés
  • Templates bilingues

🔍 Service Recherche

Recherche rapide sur tous les acteurs et entités
Capacités:
  • Auto-complétion
  • Filtres multi-critères
  • Indexation en temps réel

📈 Service Statistiques

Tableaux de bord par rôle (proviseur, parent, ministère)
Indicateurs:
  • Moyennes par classe/matière
  • Taux d’absentéisme
  • Évolution trimestrielle

4Couche Persistance (Données)

☁️ Base Centrale (Cloud)

PostgreSQL multi-tenant avec isolation par établissement
Structure:
  • Schema partagé
  • Colonne id_etablissement
  • Réplication géographique

📱 Base Locale (Offline)

SQLite embarqué dans chaque établissement
Caractéristiques:
  • Fonctionne sans internet
  • Stocke notes, bulletins, discipline
  • Léger et autonome

🔄 Service de Synchronisation

Réplication bidirectionnelle avec gestion des conflits
Logique:
  • Horodatage des opérations
  • Priorité à la dernière modification
  • Queue de sync persistante

5Flux de Données Clé : Génération d’un Bulletin

1
Professeur
Saisit les notes via l’app mobile/web
2
Système
Calcule moyennes, rang, vérifie solvabilité
3
Censeur
Valide le bulletin (workflow 2 étapes)
4
Proviseur
Approuve et publie le bulletin final
5
Parents/Élèves
Reçoivent notification + accès PDF
